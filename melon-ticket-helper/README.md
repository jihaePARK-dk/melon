# 멜론티켓 빈자리 하이라이터

멜론티켓(`ticket.melon.com`) 좌석 선택 팝업(`onestop.htm`)에서, 이미 화면에 그려진
좌석 그리드를 읽어서 **예매 가능한 좌석을 강조 표시**하고 **사이드 패널에 목록**으로
보여주는 개인용 크롬 확장 프로그램입니다.

## 이 확장이 하지 않는 것 (의도적으로 뺀 부분)

- **새로고침 자동 클릭 — 하지 않음.** 네트워크 요청을 확장이 스스로 만들지 않습니다.
- 좌석 클릭/선택 — 하지 않음
- 예매·결제 진행 — 하지 않음

콘서트(공연) 티켓은 한국 공연법상 매크로(자동화 프로그램)를 이용한 예매 행위가
별도로 규제됩니다. 이 확장은 **사람이 직접 새로고침하고 직접 클릭하는 것을
전제로**, 이미 화면에 있는 정보를 더 빨리 읽을 수 있게 도와주는 역할만 합니다.

## 동작 방식

1. 좌석 선택 팝업이 열리면 화면의 좌석 요소들을 스캔합니다.
2. 클래스명/속성(disabled, aria-disabled 등)을 보고 예매 가능 여부를 판별합니다.
3. 예매 가능한 좌석에 초록색 테두리를 표시하고, 우측 패널에 열(row)별로
   묶어서 목록을 보여줍니다.
4. 화면이 바뀔 때(예: 사용자가 직접 새로고침 버튼을 누르거나 구역을 바꿀 때)
   `MutationObserver`로 변화를 감지해서 자동으로 다시 스캔합니다.
5. 패널의 목록 항목을 클릭하면 해당 좌석 위치로 화면을 스크롤/깜빡임 표시만
   해줍니다 (좌석을 클릭하지는 않음).

## 설치 (개발자 모드 로드)

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`melon-ticket-helper`) 선택
4. 멜론티켓 좌석 선택 팝업을 열면 우측에 "빈자리 도우미" 패널이 뜹니다.

## 알아둘 점 (중요)

이 스크립트는 실제 멜론티켓 사이트의 HTML 구조를 직접 확인하지 못한 상태에서
스크린샷만 보고 만든 **1차 버전**이라, 좌석 요소를 찾는 로직(`content.js`의
`findSeatCandidates`)과 예매 가능 여부 판별 로직(`classifyAvailability`)이
실제 사이트와 안 맞을 수 있습니다.

만약 하이라이트/목록이 하나도 안 뜨거나 이상하게 뜬다면:

1. 좌석 선택 팝업에서 개발자도구(F12) → Elements 탭 열기
2. 좌석 사각형 하나를 오른쪽 클릭 → "검사(Inspect)"
3. 나온 HTML 태그 전체를 복사해서 알려주시면, 그 구조에 맞게
   `findSeatCandidates`/`classifyAvailability`/`labelSeat` 함수를 다시 맞춰드릴게요.

## 새로고침 관련

새로고침은 여전히 직접 눌러주셔야 합니다. "너무 자주 누르면 안 된다"는
제약은 이 확장과 무관하며, 멜론티켓 자체 정책을 따르시면 됩니다.
