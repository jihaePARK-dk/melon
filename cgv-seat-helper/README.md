# CGV 좌석 자동 선택 도우미

CGV 예매 화면에서 "새로고침 → 조건에 맞는 빈 좌석 찾기 → 좌석 선택"까지만 자동으로
해주는 개인용 크롬 확장 프로그램입니다.

## 이 확장이 하지 않는 것 (의도적으로 뺀 부분)

- 로그인(네이버 등) 자동화, 아이디/비밀번호 저장 — 하지 않음
- 관람권 자동 적용, 결제 자동 진행 — 하지 않음
- 보안키패드(결제 비밀번호 입력) OCR/자동 클릭 — 하지 않음

좌석이 선택되면 알림을 띄우고 그대로 멈춥니다. 이후 로그인 · 약관 동의 · 결제는
사용자가 직접 진행해야 합니다. "좌석 고르는 속도가 느린 문제"만 보완하기 위한
용도이며, 예매 전체를 무인으로 처리하는 매크로가 아닙니다.

## 설치 (개발자 모드 로드)

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더(`cgv-seat-helper`) 선택

## 사용법

1. CGV 예매 사이트에서 좌석 선택 화면까지 들어간 상태에서 확장 아이콘 클릭
2. 원하는 열 범위(예: F~O), 좌석 번호 범위(예: 16~29), 인원수 입력 후 "조회 시작"
3. 조건에 맞는 연속 좌석이 나오면 자동으로 클릭되고 멈춥니다 (알림 표시)
4. 중간에 멈추고 싶으면 "중지" 클릭

## 알아둘 점

- CGV 사이트 UI가 바뀌면 새로고침 버튼/좌석 버튼을 찾는 로직(`background.js`의
  `refreshAndCaptureSeatApi`, `selectSeatsOnPage`)이 깨질 수 있습니다. 이 경우
  실제 페이지의 버튼 속성(class/aria-label 등)을 확인해서 셀렉터를 갱신해주세요.
- 서버 부담을 줄이기 위해 조회 주기를 최소 1.8초로 제한해두었습니다. 이 값을
  임의로 줄이지 마세요.
- 개인 예매 세션 보조용입니다. 다중 탭/다중 계정으로 동시에 돌리거나, 타인 대신
  대량으로 좌석을 선점하는 용도로 쓰지 마세요. CGV 이용약관을 함께 확인해주세요.
